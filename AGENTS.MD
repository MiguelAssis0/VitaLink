Desenvolva o VitaLink seguindo integralmente os 17 documentos Markdown presentes na pasta `docs/`.

O projeto deve ser obrigatoriamente um **webapp mobile-first**, desenvolvido com React, TypeScript e Vite, com backend Java 21, Spring Boot e PostgreSQL.

A interface deve funcionar perfeitamente em navegadores desktop e mobile, além de oferecer instalação como PWA quando suportada. Não desenvolva aplicativos nativos.

Implemente os três ambientes: paciente, central de atendimento e hospital, respeitando os requisitos funcionais, arquitetura, design system, segurança, LGPD, qualidade e manutenabilidade documentados.

O MVP deverá executar um fluxo completo de emergência simulada, incluindo localização, registro da ocorrência, disponibilização autorizada de informações médicas e acompanhamento do atendimento.

Não implemente acionamento real do SAMU ou de ambulâncias. O sistema deve indicar claramente que opera em ambiente de simulação.

Antes de implementar, leia toda a documentação, organize as etapas de desenvolvimento e siga os critérios de aceite. Execute os testes durante a implementação e mantenha o projeto funcional.
