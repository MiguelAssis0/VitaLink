# Prompt para colar no Codex

Você atuará como engenheiro de software sênior responsável por construir o **VitaLink**, um MVP web de **simulação** de solicitações de emergência com compartilhamento mínimo e autorizado de informações médicas entre paciente, central fictícia e hospital fictício. Leia **todos os arquivos Markdown** da pasta `docs/` (ou deste ZIP) antes de codificar. Siga estritamente `00-LEIA-PRIMEIRO.md`, `02-REQUISITOS-FUNCIONAIS.md`, `04-ARQUITETURA.md`, `05-DADOS-E-PRIVACIDADE.md`, `06-SEGURANCA.md`, `08-DESIGN-SYSTEM-E-UX.md` e `11-CRITERIOS-DE-ACEITE.md`. Construa uma aplicação real, executável localmente, usando React/TypeScript/Vite no frontend, Java 21/Spring Boot no backend, PostgreSQL, Flyway e Docker Compose, seguindo arquitetura de monólito modular, APIs REST, autenticação segura com sessões e autorização por usuário/instituição/ocorrência, testes automatizados e interface responsiva acessível. Implemente o fluxo paciente -> pedido persistido -> central fictícia -> atribuição de hospital fictício -> visualização autorizada de resumo médico fictício, com timeline, auditoria, idempotência e tratamento de falhas. **Em hipótese alguma afirme ou simule visualmente que o SAMU foi acionado de verdade: não existe integração real; exiba 'SIMULAÇÃO' de forma inequívoca e o atalho 'Ligar 192' para emergências reais.** Não use dados médicos reais nem adicione IA de triagem clínica. Trabalhe por etapas, executando build, lint e testes após cada etapa, corrigindo problemas antes de avançar. Documente comandos, decisões técnicas, variáveis de ambiente, limitações e fluxo de demonstração no README. Se não conseguir concluir alguma parte, informe exatamente o que falta; não marque funcionalidades incompletas como prontas.

**Forma de entrega obrigatória:** um **WEBAPP mobile-first (React + TypeScript + Vite)** acessível por URL, responsivo em celular e desktop, com PWA instalável quando suportado. **Não desenvolver app nativo Android/iOS.** Siga `15-WEBAPP-E-PWA.md`, principalmente: nada de cache de dados de saúde; sem simular envio bem-sucedido quando offline; não disparar nem prometer ambulância real.
